# Automação de Programas com Python 🐍

Projeto desenvolvido em Python com foco em automação de tarefas no sistema operacional, utilizando a biblioteca **PyAutoGUI**.

O script simula ações do usuário, como pressionar teclas e digitar textos, permitindo a abertura automática de programas no Windows.

---

## 🚀 Funcionalidades

- Abertura automática do menu iniciar
- Digitação do nome do programa
- Execução do programa com comandos simulados
- Funções reutilizáveis para controle de tempo (pausa)
- Código simples e organizado

---

## 🛠️ Tecnologias Utilizadas

- Python 3.11
- PyAutoGUI
- Time

---
