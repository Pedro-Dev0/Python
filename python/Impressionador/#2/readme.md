# 🏦 Sistema Bancário Python

Sistema bancário simples desenvolvido em Python com controle de transações e registro de data/hora.

## 📋 Funcionalidades

- ✅ **Depósitos** - Adicionar valores à conta
- ✅ **Saques** - Retirar valores (com verificação de saldo)
- ✅ **Extrato** - Visualizar histórico completo de transações
- ✅ **Limite de Transações** - Máximo de 10 operações por sessão
- ✅ **Data/Hora** - Registro automático de quando ocorreu cada transação
